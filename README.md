# Abblet

**An app store where every app is remixable.**

Abblet is a platform where anyone can remix existing apps or build personal apps from scratch — in minutes, no code required.

## Development

```bash
bun install
bun dev
```

Runs at http://localhost:8090

Deploy with `./ops/deploy.sh`.

## Features

- AI-generated personal apps (Web Components)
- Store, remix, install as PWA
- Edit by chatting
